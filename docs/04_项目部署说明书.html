项目部署说明书

项目名称： 汤甜甜 · AI编程实践作品集
文档版本： V2.0

1 发布架构

本项目是无前端打包步骤的静态网站，GitHub Pages可托管index.html、src、assets及docs等资源。网页交互在浏览器运行，不要求公网服务器部署Python进程。

2 公网部署步骤

  1. 打开公开代码仓库：https://github.com/ZhijianLuan-77/TTT-homework。
  2. 确认默认main分支根目录存在index.html和所引用的相对路径资源。
  3. 进入仓库Settings → Pages。
  4. 在Build and deployment中选择Deploy from a branch，分支选择main，路径选择/(root)，点击Save。
  5. 等待GitHub完成发布，在无登录浏览器窗口打开设置页面显示的Visit site网址。
  6. 检查首页、待办、笔记、天气、五份工程文档及正式报告的链接是否返回200。

预期Pages格式： https://zhijianluan-77.github.io/TTT-homework/；是否实际可用须由浏览器/网络测试确认，不能根据路径存在直接认定部署成功。

3 本地部署

安装Python 3，解压源码，在index.html所在目录运行python start_server.py，保持终端窗口打开；根据终端显示的端口访问本地网址。Windows也可双击启动项目.bat。

4 Docker（可选）

提供Dockerfile和.dockerignore，可使用docker build -t tiantian-practicum .及docker run --rm -p 8000:8000 tiantian-practicum尝试运行。课程网站不依赖Docker，当前文档不宣称已经完成真实Docker运行测试。

5 故障排查

“连接被拒绝”通常表示本地服务器未启动或端口与实际地址不同；页面无样式时核对资源相对路径及浏览器开发者工具Network；GitHub Pages出现404时先确认Pages已启用且已成功构建；天气失败时检查网络及Open-Meteo访问情况。注意使用非登录环境检查公开访问性。
