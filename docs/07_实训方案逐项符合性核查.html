3. 关于Python与Java

课程方案第5页明确写“Python、HTML/CSS/JavaScript（或TypeScript）”。其“JavaScript”不是“Java”。本项目使用Python 3标准库提供本地HTTP服务，浏览器内业务逻辑使用JavaScript实现，符合该技术清单；不要求额外实现Java项目。不能将Python服务器启动脚本描述为Python业务后端。

4. 验收前必须做的实际操作

  1. 在自己的电脑完成网站启动，观察终端实际端口，不要关闭服务窗口。
  2. 完成教师指定零代码平台的待办网页，并保留实际项目链接或截图。
  3. 在Cursor中实际打开工程、使用AI辅助功能并保留操作记录。
  4. 使用自己的GitHub仓库提交源码，以真实提交历史和工作流结果为证据；需要上线时提交实际GitHub Pages/Vercel链接。
  5. 在目标网络检查真实天气请求，在目标电脑尝试Docker构建和运行（如教师要求）。
  6. 准备五个重要能力节点的现场问卷，以及课程要求的项目答辩与考勤。
