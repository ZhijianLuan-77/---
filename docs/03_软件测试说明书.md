# 软件测试说明书

**项目名称：** 汤甜甜 · AI编程实践作品集  
**执行环境：** Node.js / Python HTTP服务  
**文档版本：** V2.0

## 1 测试目标

验证核心业务规则、错误处理与部署资源完整性，为课程软件交付提供可重复的结果证据。

## 2 测试方法与环境

执行`node --test tests/*.test.mjs`检查核心JavaScript纯函数；执行`python tests/http_smoke.py`在真实本地HTTP服务下检查主页、3个JavaScript资源、CSS和SVG图标。天气API使用模拟响应进行隔离测试，未据此声称真实联网查询已通过。

## 3 测试结果摘要

| 测试类别 | 已运行数量 | 结果 | 判定 |
|---|---:|---|---|
| 核心单元测试 | 24 | 24通过，0失败 | 通过 |
| HTTP资源检查 | 6 | 6通过 | 通过 |
| 真实第三方天气查询 | — | 未在当前测试环境作端到端联网确认 | 待发布后实测 |
| Docker实际容器运行 | — | 提供Dockerfile但未验证容器运行 | 非必需补充 |

## 4 典型测试用例

| 编号 | 场景 | 预期结果 |
|---|---|---|
| T01 | 新建合法任务 | 生成任务并正确展示 |
| T02 | 空名称或非法日期 | 拒绝不合法输入 |
| T03 | 按关键字搜索/状态筛选 | 结果集合符合条件 |
| T04 | 任务完成或重新打开 | 统计随状态更新 |
| T05 | 导入结构异常JSON | 给出提示且不覆盖合法数据 |
| T06 | Markdown文本中包含脚本内容 | 预览不会执行脚本 |
| T07 | 在窄屏下切换模块 | 导航及内容可操作 |
| T08 | 天气API超时/拒绝 | 页面显示错误提示，不伪造天气 |

## 5 局限与改进

浏览器交互测试曾使用隔离脚本注入和天气模拟数据，不等同于线上端到端真实API调用。正式发布后，须使用非登录浏览器窗口打开公开网址，分别点击四个模块、打开所有PDF下载链接，并实测天气查询。

## 6 复现实验

本地进入含`package.json`的根目录，运行`npm test`；再执行`python tests/http_smoke.py`。终端结果保存在`tests/单元测试结果.txt`及`tests/HTTP服务测试结果.txt`，以执行时输出为准。
